# RPDsGrove

Public music app at /rpdsgrove/, deployed through the existing DreamHost workflow. Eight ready-to-share SoundBreak songs are included. Artwork is original SVG artwork generated for this app. MP3s stream from SoundBreak; no account-connect links, generation prompts or credentials are published.

Features: search, local playlists (create/rename/delete and add/remove tracks), favorites, listening history, queue, shuffle, repeat one/all, seek, volume, media-session controls, installable PWA, theme color, Google Cast default receiver, Safari AirPlay picker, local music import, and remote listening rooms. Browser-local state is labeled in the UI. The shell is cached; music still requires internet.

A player starts a room and shares its fragment link. Remote controls require the 96-bit room code. Receiver heartbeat/end require an additional 256-bit secret held only in the player tab. Rooms and uploaded audio are temporary files outside the web root. Rooms expire after 24 hours; uploaded audio expires after 90 days. Room creation, upload size, per-address uploads, shared storage, command queues and command rates are bounded. Commands expire after 30 seconds and require an online heartbeat. Song URL validation permits only HTTPS MP3 files on audio.soundbreak.ai or expiring same-origin uploaded-media URLs; the PHP endpoint does not proxy or fetch arbitrary URLs. Refreshing/closing the player ends its room connection; start and share a new room afterward. Room and media URLs are bearer capabilities: anyone given a link can control that player or play the corresponding temporary audio.

Imported audio stays in IndexedDB for local playback. It is uploaded only when the user chooses Google speakers or remote playback, to create a temporary media URL. The app checks file extension and detected MIME type; only supported audio types up to 100 MB are accepted. Upload copies live outside the deploy-synced web directory and are removed on expiry or storage cleanup.

The upload handler needs PHP upload limits above 100 MB; the included `.user.ini` sets a 101 MB file limit and 102 MB request limit. Uploaded files and rate-limit state are stored in a private directory outside the document root. `RPDGROVE_PRIVATE_DIR` can override the default parent-of-document-root location when the host requires a specific persistent path. Use `npm run test:all --prefix tests` to run the chord, browser, and PHP API suites; set `PHP_CLI` to the PHP executable when it is not on `PATH`.

Song identification uses AudD's standard recognition API. It is opt-in per tap, captures up to 8 seconds, allows five requests per network per hour, and returns only title/artist/album metadata. The sample is forwarded for recognition and is not saved by Grove. Store `audd-token.txt` in the private root outside the document root (default `<parent-of-document-root>/.rpdsgrove-private/audd-token.txt`), or configure `AUDD_API_TOKEN` / `RPDGROVE_AUDD_TOKEN_FILE` in the PHP server environment. Restrict the token file to the PHP account; without a token the endpoint returns a configuration error. AudD may charge for requests according to the account plan. Search links open external chord/lyric results; Grove does not scrape lyrics. Only add lyrics you own, have permission to use, or that are public domain. `allow_url_fopen` must be enabled for the PHP HTTPS stream wrapper used by the recognition proxy.

Pair speakers on the local network using Chrome Cast or Apple Safari AirPlay. Keep the player tab awake for remote controls and automatic queue progression. Google Home can create/manage Nest groups; HomePods use AirPlay 2. This does not register RPDsGrove as a Google voice music provider and does not synchronize Google and Apple speaker ecosystems. Browser autoplay/device pairing still require an initial gesture. Real speaker hardware was unavailable during development.

SoundBreak's connected tool supplies a capped recent-song list, not a website API token or a library-sync API. Further direct MP3 URLs can be added in the app on that device. No automatic import of future tracks is claimed.

Validation: PHP syntax; JavaScript syntax; actual SoundBreak MP3 playback; browser search/favorite/playlist persistence; repeat/skip behavior; two-browser room creation, song change, pause and ending; rejected unauthorized heartbeat and invalid media origin; responsive mobile layout and accessible settings. Cast/AirPlay hardware validation remains required on site.
